# Deskripsi Sistem

## Latar Belakang
Pengelolaan akademik yang masih manual (kertas atau spreadsheet terpisah)
rentan terhadap data ganda, keterlambatan informasi, dan kesalahan input nilai.

## Ruang Lingkup
1. Pengelolaan data master (mahasiswa, dosen, mata kuliah, program studi, ruang)
2. Penjadwalan kuliah
3. Kartu Rencana Studi (KRS)
4. Input nilai dan Kartu Hasil Studi (KHS)
5. Transkrip nilai dan laporan akademik

## Alur Singkat
Admin menyiapkan data dan jadwal → Mahasiswa mengisi KRS → Dosen wali
menyetujui KRS → Perkuliahan berjalan → Dosen menginput nilai →
Mahasiswa melihat KHS dan transkrip.

## Entitas Utama
Mahasiswa, Dosen, Mata Kuliah, Program Studi, Jadwal, KRS, Nilai.
