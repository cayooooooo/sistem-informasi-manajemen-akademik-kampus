# Kebutuhan Fungsional

| Kode | Kebutuhan | Pengguna |
|------|-----------|----------|
| KF-01 | Login dan logout sesuai peran | Semua |
| KF-02 | Mengelola data mahasiswa, dosen, dan mata kuliah | Admin |
| KF-03 | Mengelola jadwal kuliah dan ruang | Admin |
| KF-04 | Mengisi dan mengubah KRS pada periode aktif | Mahasiswa |
| KF-05 | Menyetujui atau menolak KRS | Dosen wali |
| KF-06 | Menginput nilai mahasiswa | Dosen |
| KF-07 | Melihat KHS dan transkrip nilai | Mahasiswa |
| KF-08 | Mencetak laporan akademik | Admin |

# Kebutuhan Non-Fungsional
- Keamanan: akses berdasarkan peran dan kata sandi terenkripsi
- Ketersediaan: sistem dapat diakses selama periode KRS dan input nilai
- Kemudahan penggunaan: antarmuka sederhana dan responsif
