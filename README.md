# Sistem Informasi Manajemen Akademik Kampus

Repository ini berisi dokumentasi Sistem Informasi Manajemen Akademik (SIMAK) kampus.

## Deskripsi
Sistem informasi untuk membantu kampus mengelola kegiatan akademik secara
terintegrasi, mulai dari data mahasiswa dan dosen, mata kuliah, jadwal kuliah,
pengisian KRS, hingga input dan rekap nilai (KHS/transkrip).

## Tujuan
- Mempermudah pengelolaan data akademik
- Mengurangi pekerjaan manual dan kesalahan pencatatan
- Mempercepat layanan akademik bagi mahasiswa, dosen, dan staf

## Pengguna Sistem
| Pengguna | Peran |
|----------|-------|
| Admin Akademik | Mengelola data master, jadwal, dan periode akademik |
| Dosen | Melihat jadwal, menginput nilai, menyetujui KRS (dosen wali) |
| Mahasiswa | Mengisi KRS, melihat jadwal, KHS, dan transkrip |
